# Olympiad Recorder

Программа для записи устных ответов участников олимпиады по английскому языку. При обычном запуске открывается окно PyQt6 с полем кода участника, кнопками записи, списком трёх последних файлов и путём к папке. Целевая ОС — Windows 10 LTSC x64. Аудиозахват и кодирование основаны на [QuickAudioRecorder](https://github.com/lukmay/QuickAudioRecorder).

## Работа с программой

1. В меню **Настройки** выберите **Основные настройки…**, чтобы указать микрофон, папку и формат. Этот диалог также открывается сочетанием `Ctrl+,`. По умолчанию используются системный микрофон, MP3 с битрейтом 192 кбит/с и папка `Recordings` рядом с `OlympiadRecorder.exe`. При запуске из исходников папка находится рядом с `main.py`. Также доступны WAV и FLAC.
2. Введите код участника и проверьте имя файла под полем. Можно использовать до 64 латинских букв, цифр, дефисов и знаков подчёркивания. Пробелы по краям убираются, ведущие нули сохраняются. Системные имена Windows, например `CON` и `COM1`, недопустимы.
3. Нажмите **Начать**, затем **Стоп**. Поле кода очистится сразу, а имя сохраняемого файла останется привязано к начатой записи. Пока идёт запись или сохранение, поле ввода, настройки и закрытие окна заблокированы. После сохранения в папке появится файл вида `00125.mp3`.
4. Если файл уже существует, выберите другой код или папку. Если одноимённый файл появился во время записи, завершённое аудио останется рядом под именем вида `.oly-00125-….mp3`. Путь указан в панели ошибки. Этот файл можно перенести или переименовать вручную.
5. Если запись прервалась из-за устройства, программа попытается сохранить записанный фрагмент и сообщит результат. При сбое экспорта уже записанный исходный WAV остаётся во временной папке Windows. Скопируйте его по пути из панели ошибки до очистки временных файлов.

Чтобы открыть папку с записями в Проводнике, нажмите на путь внизу окна.

Пункт **Все настройки…** открывает исходное окно QuickAudioRecorder со всеми разделами. Сохранённые параметры микрофона, папки и формата видны в обоих диалогах. В основном окне работают запись в моно, нормализация, автостоп, копирование файла в буфер и глобальные горячие клавиши. Горячие клавиши запуска используют введённый код участника и могут выбрать микрофон, системный звук или оба источника.

Щелчок по значку, уведомления в трее и перенос файла во временную папку после копирования действуют в режиме трея, который запускается через `OlympiadRecorder.exe --tray`.
